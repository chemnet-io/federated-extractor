MS5.2 Asset description

Describe an asset lead by InfAI where it encompasses a collection of different services that can be executed with Knowledge Graphs and/or Federated portions from it. It’s name is "Federated knowledge representation through graphs" and is available for all SMARTY partners and in some portions is also available as an open-source service. It provides the following funcionatinalities and characteristics:
    1. Automatic Knowledge Extractor from documents, being it papers, patents or hardware manuals:
        * REST API with tokens to securely and privately receive the documents from SMARTY partners;
        * LLM-based extractor for the documents into RDF Knowledge Graphs based on an ontology (e.g., CEF's DAOnt that is KCONG's backbone)
        * Access controllable QLever triple-store with support for MCP access for other SMARTY partners such as CMPG.
    2. Node-to-node similarity- or Graph Neural Network-based search for Knowledge Graphs:
        * command-line interface and file preparation for choosing type you want to search;
        * different graph-embeddings, text-embeddings propagation or Graph Neural Network methods are available.
    3. Open-source private LLM-based Text-to-SPARQL method designed to be used with Edge devices:
        * Two step QLoRA-based fine-tuning with reasoning and rewards in mind for lower amount of parameters models
        * In-development automatic generation of training data for the fine-tuning pipeline
        * Command-line interface Text-to-SPARQL evaluation tool that was already used for in two editions of the International Text2SPARQL challenge
        * Web interface for setting up the prompts, saving and running the queries

Gemma 4:

Federated Knowledge Representation through Graphs is a comprehensive technical asset. It serves as a suite of services designed to transform unstructured data into actionable intelligence through the use of Knowledge Graphs (KGs) and federated architectures.

The asset is primary available to all SMARTY partners, with select components released as open-source services to foster transparency and community adoption. By bridging the gap between raw documentation and semantic querying, the asset enables partners to scale their knowledge management capabilities across distributed environments.

The asset is structured into three core functional pillars:

1. Automated Knowledge Extraction Pipeline
This service handles the ingestion and transformation of complex technical documents (such as academic papers, patents, and hardware manuals) into structured KGs.

Secure Ingestion: It utilizes a REST API with token-based authentication, ensuring that documents shared by SMARTY partners are transmitted and handled with strict privacy and security.
LLM-Driven Extraction: The system employs Large Language Models (LLMs) to extract entities and relations, mapping them into RDF Knowledge Graphs. This process is governed a known ontology, in the case of SMARTY, CEF's DAOnt (the backbone of KCONG) is used to guide the extraction and ensure interoperability and semantic consistency.
High-Performance Storage: Extracted structured data is housed in an access-controlled QLever triple-store. To facilitate seamless integration with other partners (such as CMPG), with support to MCP (Model Context Protocol) access, allowing for federated data consumption.

2. Advanced Graph Analytics and Search
Beyond simple queries, the asset provides sophisticated tools for discovering hidden patterns and similarities within the Knowledge Graphs.

Flexible Search Mechanisms: Users can perform node-to-node similarity searches or leverage Graph Neural Networks (GNNs) to identify related concepts.
Customizable Embeddings: The service supports various methodologies, including graph-embeddings, text-embedding propagation, and specialized GNN methods, allowing users to choose the most effective approach based on the nature of their data.
Developer Interface: The tool is managed via a command-line interface (CLI) with structured file preparation, ensuring that the search type and parameters are precisely configured for the desired outcome.

3. Edge-Ready Text-to-SPARQL Interface
To democratize access to the Knowledge Graphs without requiring deep expertise in SPARQL, InfAI provides an open-source, private LLM-based translation layer optimized for resource-constrained environments.

Edge Optimization: Specifically designed for Edge devices, the system utilizes a two-step QLoRA-based fine-tuning process. This approach focuses on reasoning and reward-based learning, allowing smaller parameter models to achieve high accuracy in query generation for the target KG.
Automated Pipeline: The asset includes an in-development pipeline for the automatic generation of training data, reducing the manual effort required to refine the fine-tuning process.
Proven Performance: The reliability of this method is validated by a CLI evaluation tool that has been successfully deployed in two editions of the International Text2SPARQL challenge.
User Accessibility: For non-technical users, a web interface provides a streamlined environment for setting up prompts, saving queries, and executing searches against the federated graph in different triple-stores.
